# 🧮 CLI Calculator in Python

Welcome to the **CLI Calculator** (Command Line Interface) — a simple but well-structured project built in Python to run directly in the terminal.

It demonstrates good practices of modularization, error handling, and user interaction on the command line.

---

## 🚀 Features

### ✅ Basic Operations

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division

### ⚡ Extras

* 🔢 Exponentiation
* 🧠 Square root
* 🚫 Error handling (such as division by zero and negative numbers for square root)

---

## 🧩 Project Structure

```
calculadora_cli/
│
├── main.py       # Main file (interactive menu)
├── calculos.py   # Mathematical functions
├── utils.py      # Helper functions (input and menu)
└── README.md     # Project documentation
```
